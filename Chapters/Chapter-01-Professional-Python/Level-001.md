> "A strong building is not judged by its roof, but by its foundation."

---

# Mission Brief

Welcome to **Project APEX**.

Today you are not beginning a Python course.

You are beginning the process of becoming an engineer.

That distinction is important.

Programming is not the act of writing code.

Programming is the process of solving problems by giving precise instructions to a computer.

Python is simply the first language we will use to learn that skill.

Throughout Project APEX you will repeatedly discover that languages, libraries and frameworks change, but problem-solving principles remain.

Level 001 is where those principles begin.

---

# Why This Level Exists

Many beginner tutorials start like this:

```python
print("Hello, World!")
```

They show *how* to print text.

Very few explain **why** this line matters.

Project APEX approaches learning differently.

Before we write larger programs, we first build a mental model of what happens when a computer executes code.

By the end of this level you should understand:

- what a program actually is;
- how Python executes instructions;
- how information is stored;
- how information moves through a program;
- why readable code matters.

These ideas form the foundation of everything we will build later—from machine learning models to research software.

---

# Learning Outcomes

By the end of this level you should be able to:

- Explain what programming is in your own words.
- Explain what an algorithm is.
- Describe how Python executes a program.
- Use `print()` correctly.
- Store information using variables.
- Explain the purpose of the four basic Python data types.
- Receive user input using `input()`.
- Write clean, readable Python code.
- Experiment confidently without fear of making mistakes.

You are **not** expected to master Python after this level.

You are expected to build a strong foundation.

# Learning Topics

This level contains eight learning topics.

Each topic builds directly on the previous one.

Do not skip topics.

---

## Topic 1 — What Is Programming?

**Estimated Time:** 45–60 minutes

### Objectives

Understand:

- what a program is;
- what an algorithm is;
- why programming languages exist;
- why Python is widely used.

### Key Idea

A program is a collection of instructions.

A computer follows those instructions exactly as written.

It cannot guess your intention.

One incorrect instruction can change the behaviour of the entire program.

---

## Topic 2 — The Engineer's Mindset

**Estimated Time:** 20–30 minutes

No coding yet.

Instead, understand these principles.

- Engineers solve problems.
- Bugs are expected.
- Documentation is part of programming.
- Searching for information is normal.
- Copying without understanding is harmful.

These habits are more valuable than memorising syntax.

---

## Topic 3 — Running Python

**Estimated Time:** 45 minutes

Learn:

- creating Python files;
- the `.py` extension;
- running programs;
- the terminal;
- execution from top to bottom.

### Goal

Understand what happens between pressing **Run** and seeing the output.

---

## Topic 4 — Output with `print()`

**Estimated Time:** 45–60 minutes

Learn:

- displaying text;
- displaying numbers;
- multiple arguments;
- escape characters;
- using output for debugging.

Remember:

`print()` is not just for displaying results.

Professional developers also use it to understand what their programs are doing.

---

## Topic 5 — Variables

**Estimated Time:** 2 hours

This is the most important topic in this level.

Learn:

- variables;
- assignment;
- reassignment;
- naming conventions;
- dynamic typing;
- conceptual memory storage.

Spend extra time here.

A deep understanding of variables will make future chapters much easier.

---

## Topic 6 — Basic Data Types

**Estimated Time:** 90 minutes

Learn the purpose of:

- `int`
- `float`
- `str`
- `bool`

Do not memorise definitions.

Understand why each data type exists.

---

## Topic 7 — User Input

**Estimated Time:** 60 minutes

Learn:

- `input()`;
- user interaction;
- converting input values;
- why `input()` returns text.

---

## Topic 8 — Writing Readable Code

**Estimated Time:** 45 minutes

Learn professional habits early.

Focus on:

- indentation;
- spacing;
- comments;
- meaningful names;
- organisation.

Good habits become automatic through repetition.

# Common Beginner Mistakes

Avoid these habits whenever possible.

- Trying to memorise syntax.
- Copying code without understanding it.
- Writing code without running it.
- Ignoring error messages.
- Being afraid to experiment.
- Giving variables unclear names.
- Rushing through concepts.

Remember:

Every experienced programmer has made these mistakes.

The goal is not to avoid mistakes.

The goal is to learn from them.
